# Provider 작업

현재 환경에서 인증된 CLI/API/connector의 조회·생성·갱신·결과 확인 기능을 실제로 확인해 선택한다. GitHub/Gitea의 명령 옵션이나 payload를 추측해 공통 계약으로 고정하지 않는다.

저장소, remote, head/base, 공개할 commit 범위, 제목·본문, 대상 PR, 요청된 작업을 확인한다. PR 생성 전 같은 head/base의 기존 PR을 조회해 중복을 피한다. 필요한 일반 push는 확정된 committed head에 한정하고 미커밋 변경을 자동 commit하지 않는다. Draft 여부는 사용자 지정, 저장소 관례, 도구 기본값 순서로 판단하고 실제 상태를 보고한다.

응답 유실이나 timeout 후에는 원격 ref와 PR 목록·대상을 먼저 조회한다. 성공 여부가 미확인인 동안 생성 요청을 반복하지 않는다. 기존 PR을 찾았다는 이유만으로 제목·본문을 임의 덮어쓰지 않는다. 설명 갱신은 지정한 PR과 필드만 수정하고 다시 조회한다. 도구·권한이 없으면 준비된 제목·본문과 미완료 실행을 보고한다. 부분 실패는 완료·실패/미확인·보존 상태·다음 조치를 분리한다.
